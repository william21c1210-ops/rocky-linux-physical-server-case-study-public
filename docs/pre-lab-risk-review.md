# 사전 안전 검토

> Pre-lab risk review: 물리 NIC 실험 전에 접속 경로와 중단 조건을 정리한 기록이다.

## 문서 적용 범위

이 검토는 DL360 Gen9 · Network / SSH test unit의
`eno1` Link/Carrier 실험 전에 작성한 내용이다.
Storage / OS provisioning unit과 모델 미확정 유휴 서버의 작업에는 적용하지 않는다.

## 경로 분리

- `eno4`는 기존 주 접속과 외부 Route 경로로 유지한다.
- `eno1`만 보조 Link/Carrier 실험 대상으로 사용한다.
- `eno2`와 `eno3`은 변경하지 않는다.
- 한 번에 노트북 쪽 테스트 케이블 연결 상태 하나만 바꾼다.

## 복구 접근 준비

작업 전에 iLO Remote Console과 로컬 콘솔 로그인이 가능한지 확인했다.
이 접근 수단은 SSH 문제가 생길 때 사용할 준비 경로였다.

실제 SSH 장애는 발생하지 않았고 iLO를 이용한 복구도 수행하지 않았다.
따라서 콘솔 복구 능력을 실제 상황에서 확인한 결과로 해석하지 않는다.

## 중단 조건

다음 중 하나가 나타나면 추가 물리 동작을 멈춘다.

- `eno4` Link 변화
- 외부 목적지 Route가 `eno4`를 선택하지 않음
- 기존 SSH 접속 상태 변화
- 대상 포트나 케이블을 확실히 구분할 수 없음
- 예상하지 않은 사용자 영향

## 기록과 공개 범위

식별정보가 포함된 원본과 공개 증거를 분리한다.
공개 증거에서는 서버명, 주소, 계정, MAC과 위치 정보를 대체하거나 제거한다.

관찰한 사실과 해석을 구분하고 미수행 항목은 그대로 표시한다.
이 사전 검토 당시에는 사진을 공개 증거로 포함하지 않았다.
이후 Public Snapshot에는 식별정보를 제거한 작업 사진을 보조 증거로 추가했다.

별도 공식 변경 티켓은 사용하지 않았다.
서버 사용 가능 전달, 다른 로컬 사용자 부재와 콘솔 접근처럼 직접 확인한 범위만 기록한다.

실습 전부터 있던 일반 하드웨어 상태 경고는 이번 NIC 실험의 원인으로 다루지 않는다.
해당 경고의 진단과 복구는 이 작업 범위 밖이다.
